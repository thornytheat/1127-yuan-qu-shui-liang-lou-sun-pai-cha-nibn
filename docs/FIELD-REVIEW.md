# 分区核账与夜班复盘

按分区和夜窗取得供水总表，再扣掉池容变化和合法冲洗支出，与可用分表区间的有理数升数核对。总或分表覆盖不足时仅保留差额待查。有效供水量大于零且差额严格超过十五个百分点时标记高损耗。

阀门试验按树状消防隔离图检查。每次隔离后测得持续流量下降，给覆盖此支路的候选段增加证据。失准、迟到和未知阀不加入候选权重，独立有效次数或权重不够时保留待确认状态。

运维人员可复核去掉一晚后压力校正基线的波动，以及应急班组退出或封区时队列里的未服务安全类工单。演练重新计算，不覆盖实际配次。

## 交班名单裁决

工作台在「巡检配次」证据和「下一班巡检名单」面板给出交班结果。汇总口径：留巡表数、修复释放表数、准时回执数、晚到回执数与未采用回执条数。每张表给出本期分级、回执工单、复测夜窗、供压偏差与裁决依据。

- 晚到回执（复检分钟晚于复核截止）只进入晚到清单，留到下一批复核，本期分级与名单均不改动。
- 回执分区与巡检分区不同、或该表本期没有已派单记录时，回执不计修复，表位按原分级继续跟进。
- 复测夜窗必须在修复完成之后开启且覆盖达标；缺测、被隔离或供压相对偏差超过 10% 时，即便回执读数回落也不采信，继续留巡。
- 只有回执确认漏点、修后净回落且修后夜窗余流低于最小异常流量，才释放听漏名额；同批复盘只读不写，不新增派工。
